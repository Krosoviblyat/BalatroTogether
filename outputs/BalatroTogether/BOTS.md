# Local native bots

On Windows x64, host a table with the total number of seats you want (humans plus bots). In the lobby, choose **Add Bot** on an empty seat. Up to three companions join automatically, ready themselves, play hands, discard, cash out, shop and ready for the next blind. Start Run remains controlled by the human host. Use Remove Bot before starting to free a seat for a friend. Fast Restart also resets every bot's native deck and decision state.

Bots run the user's installed Balatro executable as hidden local companions. The launcher uses Lovely's supported `--disable-console` flag, Windows startup hiding and visibility checks scoped to companion PIDs; you manage only your playable game window. Each bot owns a real native deck, money, shop, joker triggers and contribution stream. Scores are never granted or fabricated. Bots use the same selected party deck, seed, difficulty and shared target as humans. No API key, AI service, Python or extra download is needed. They consume additional CPU/RAM because each seat runs a native game process.

The planner enumerates legal one-to-five-card plays and compares estimated chips × mult, using current hand levels, enhancements, editions, held steel, retriggers and explicit rules for many common vanilla jokers. It considers Psychic/Eye/Mouth/Flint restrictions. Discards compare several pair, flush, straight and enhanced-card holds using 16 sampled draws per candidate. Sampling uses remaining deck composition sorted independently of draw order, a private deterministic PRNG, and no native RNG calls. The planner does not inspect another player's private hand or peek at the next card.

Shop choices favor immediate scoring and useful upgrades, preserve interest when practical, replace weaker sellable jokers, avoid several destructive/low-value purchases, buy selected permanent vouchers, use planets and selected safe tarots, and limit reroll spending. Bots wait for native shop construction/events to settle before acting. Decisions are spread over frames with a small planning budget.

These are heuristic bots, not an exact implementation of every joker interaction or an unbeatable solver. Exotic joker combinations, Blueprint/Brainstorm placement, targeted tarot optimization, booster-pack drafting and complete boss coverage are not solved. Bots currently skip booster packs. They can lose; difficulty and seed matter. Native tests and their limits are recorded in TEST_RESULTS.md.

Host exit/Leave closes its companion processes. A companion watches its parent process and exits if the host disappears. Unexpected companion errors are logged and exit the child instead of opening a desktop crash screen. If a bot disconnects during a run, reconnect recovery may resume a transient connection; otherwise retire the absent seat through the host menu.

Companions receive separate save identities named BalatroTogetherBot..., and private copies of Steamodded, Amulet, Cryptid and Together under the host save directory's `together-bots/` folder. Lovely logs/dumps must not be shared between processes. Other additional mods and the private development LabHarness are not copied. Generated profiles/cache folders may remain after exit so logs are available. They contain no changes to your ordinary profiles. Close all companions before manually removing generated bot cache/profile folders.

Donation Box: select a bot's name in Send To before donating. A ready bot unreadies itself, receives an addressed gift when capacity permits, then readies again. Public Everyone gifts remain available for humans. Donated stats/editions use the same native card reconstruction as human claims. Bots use gifted consumables only when their current strategy supports them. Parent monitoring continues during pending transfers so a host crash cannot leave a child waiting on a donation indefinitely.

Cryptid: companions inherit the host profile ruleset and overrides. First-time setup and personal Cryptid music prompts are bypassed only in hidden companion profiles. Native Continue unlock notices are acknowledged automatically; an Amulet calculation overlay is never aborted. Finite Omega values remain available to generic estimates, but the planner does not model every exotic Cryptid effect.
