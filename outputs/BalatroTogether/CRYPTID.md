# Cryptid co-op build — 0.6.1-dev

Install the same bundle on every computer: Together 0.6.1-dev, Cryptid 0.5.17c, Amulet 3.6.1, Steamodded 26.1002.0 and Lovely 0.10.0, with Steam Balatro 1.0.1o-FULL for Windows x64. The easy installer includes these components and backs up recognized old copies before replacing them. Your own game is required.

Cryptid's available decks appear in the host's deck selector. Together initializes the native run-selection defaults and broadcasts the host's choices before applying the deck. This fixes the missing Antimatter choices crash and enables the Edition, Enhancement, Suit and Seal deck effects. All 38 selectable decks passed start and same-seed restart checks. All players use the selected deck and seed, White Stake and the same co-op schedule, continuing automatically into endless after ante eight. Shops, cards, money and hand choices remain individual. Everyone must select the same Cryptid ruleset and overrides in their own profile before joining. Bots inherit the host's ruleset. Joining checks active mod versions and gameplay configuration; personal music preferences may differ.

Amulet's Omega backend is enabled for native large scores. Together preserves finite large values in shared targets, contributions, summaries and donation abilities. Network messages contain bounded numeric data; they never evaluate received Lua. Ordinary graphics coordinates and progress ratios remain ordinary numbers. The wire supports explicit Omega arrays up to 64 layers with finite nonnegative components at most 2^53−1. Ordinary IEEE score reports are limited to 1e100 to prevent addition overflow; larger native Amulet scores use the Omega envelope. Infinite/NaN values and special implicit arrays are unsupported. An unsupported score is refused with a message rather than accepted as a corrupt score. This is not support for every theoretical Amulet number.

The Donation Box accepts owned vanilla and Cryptid Jokers, Tarot, Planet, Spectral and Code consumables. Built-up ability data, finite Omega values and supported Cryptid editions travel through the existing reservation/receipt system. Recipients need space. Eternal/debuffed cards, playing cards, vouchers, cards holding storage or another face, and Jokers under a temporary ://Multiply effect cannot transfer. Other mods' custom cards and external card-object graphs are unsupported. Wait for animations to finish before donating.

Shared progression takes precedence over individual ante changes. Boss cash-out advances one shared ante; personal ante reductions/jumps are suppressed. This prevents the Joke boss from moving one native run to ante eight while the party expects ante two. Hieroglyph, Petroglyph, Asteroglyph, Redeo, Analog, ://Revert, ://Semicolon and the Lua Console are excluded or guarded in co-op. Skips and boss rerolls remain disabled. Single-player behavior is unchanged. These are deliberate co-op rule adaptations, so this build does not reproduce unrestricted single-player Cryptid progression.

The shared target uses the host's selected blind base/multiplier, deck scaling and player count. Individual dynamic blind-size changes are normalized to that shared target; they do not independently reprice it for one player. Cards still resolve their native scoring effects. This adaptation matters for builds or bosses whose main effect changes the blind's chip requirement.

Gold/red dice, the Boss Reward Wheel with its Space jackpot challenge, separate personal/team Bet Pots, party restart and the registered-owner slash admin panel remain available. The UI adds spring button lift, press squish, modal bounce, glow and drifting Cryptid-themed diamonds. Reduced Motion and animation intensity apply to these effects.

This is a pinned development compatibility build. Extra mods, all later Cryptid effects/build combinations, remote account Steam relay behavior, balance, and ordinary full-run victories are not certified. Bots use heuristic card/hand estimates and native game scoring; they do not fully model every Cryptid exotic synergy. Start a new party after updating; do not update files during a match. See TEST_RESULTS.md for the exact tested fixtures.

Upstreams: [Cryptid](https://github.com/SpectralPack/Cryptid/tree/v0.5.17c), [Amulet](https://github.com/frostice482/amulet). The full package retains exact upstream source archives and license texts. Amulet's Thunderstore manifest.json is omitted only from the installed Mods tree because Steamodded treats it as malformed mod metadata; the original remains in its source ZIP.
