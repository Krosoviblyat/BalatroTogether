BALATRO TOGETHER + CRYPTID 0.7.0-dev — WINDOWS x64

EASY INSTALL
1. Everyone closes Balatro.
2. Right-click the Easy-Installer ZIP and select Extract All.
3. Open the extracted folder. Double-click Install Balatro Together.exe.
4. Click Install. When it finishes, click Play Balatro Together.
   On first launch, complete Cryptid's welcome and choose Mainline.
5. Press F8. Host a Table -> Steam -> Open Table -> Invite Friends.
   Friends accept the invitation and confirm Join Friend in Together.
   Everyone Ready Up; the host clicks Start Run.

The installer includes Lovely 0.10.0, Steamodded 26.1002.0, Amulet 3.6.1,
Cryptid 0.5.17c and Together 0.7.0-dev. No extra downloads are needed.
You need your own Steam copy of Balatro 1.0.1o-FULL on Windows x64.
If the game is not found, click Find game and select Balatro.exe.
Install the SAME bundle on every player's computer. Keep Steam online.
Steam mode does not require an IP, PIN or port forwarding.

WHAT HAPPENS TO OLD VERSIONS?
Old Together, Steamodded, Cryptid, Amulet and Talisman installations,
including recognized renamed copies and extraction wrappers, move to a
dated backup outside Mods. The installer then installs fresh matched
components; it does not merge their files. Saves are backed up too.
Backup location: %AppData%\BalatroTogether\Backups
PreviousMods preserves old mod paths. Nothing is permanently deleted.
A failed install restores the previous components automatically.
Unrelated identified mods stay put; conflicting multiplayer mods move to
the backup. Unknown DLLs require identification in the manual guide.
The installer refuses to modify an open game.

MANUAL INSTALL FALLBACK
Use Manual Install.zip if the unsigned installer cannot run. Extract it
outside the game and Mods folders. Close Balatro and copy your entire
%AppData%\Balatro folder to a safe location first.
In Steam: right-click Balatro -> Manage -> Browse local files.
Copy Game Folder\winmm.dll beside Balatro.exe. Never overwrite an unknown
winmm.dll. Identify/back up old Lovely version.dll outside the game folder
before installing. Do not replace the game's Steam libraries.
Move prior Together, Steamodded, Cryptid, Amulet and Talisman components
outside %AppData%\Balatro\Mods. Keep their backups. Copy ALL FOUR folders
from this package's Mods folder directly into %AppData%\Balatro\Mods:
  smods-26.1002.0
  Amulet
  Cryptid
  BalatroTogether
Do not put the whole extracted package in Mods. The final paths include
Mods\Cryptid\Cryptid.lua and Mods\BalatroTogether\main.lua.
Keep Licenses and Sources with the package when sharing it.
Launch through Steam or the quiet Play Balatro Together shortcut.

PLAY AND FEATURES
Choose the same Cryptid ruleset/overrides on every human player's profile.
Different mod versions or gameplay settings are rejected before joining.
Cryptid decks appear in the host's deck selector. Amulet Omega mode is
required and enabled automatically for large cooperative scores.
Your decks, shops, hands and money remain individual; blind progress and
team scores are shared. Fast Restart resets the party's run.
F8 -> Donation Box: give Jokers and Tarot/Planet/Spectral/Code cards to
Everyone or a teammate. Stay unready between blinds/in the shop. The
recipient needs inventory space. Eternal, storage and double-sided cards
cannot be donated. Bots only take gifts addressed to them.
F8 -> Bet Pot: a won blind banks bets plus a rounded-down 37.5% bonus.
The host splits team winnings evenly among active players.
Personal bets bank a smaller 15% bonus; only their owner can collect them.
Click TYPE AMOUNT in either pot to enter an exact whole-dollar bet.
Ctrl+A selects all; Ctrl+V pastes. Enter finishes editing; click BET to
confirm. Limits: $1-$10,000 and no more than your available wallet.
A loss burns the pending bets in each pot, preserving saved winnings.
F8 -> Reward Dice: each two won blinds earns a gold d6 ($5 per pip) and
red d20 (+Mult on hands in the next blind). Boss wins earn a wheel spin.
FUCK THE TABLE uses one earned spin: press/release Space 32 times within
eight seconds to guarantee the jackpot. Holding Space does not count.
Missing the QTE gives your ordinary wheel spin.
Endless is automatic: after the ante-eight boss, the party continues to
ante nine with its builds, rewards and pots. Start fresh after updating.
The refreshed UI has quieter felt panels, staggered card entrances,
button lift/press feedback and smooth open/close transitions. Use the
top navigation to switch between Table, Gifts, Bet Pots and Rewards.
Settings -> Reduced Motion disables bounce and particle movement.
The registered Steam owner can press / for admin/recovery controls.
