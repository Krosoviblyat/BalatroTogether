# Windows installer source

This is the original, AI-assisted Balatro Together file installer, released under the included MIT license. It embeds the full install package, verifies its SHA256, and copies only its four Mods components and the pinned Lovely DLL. It never downloads executable code at install time.

Setup 5 (installer 0.6.1.0) installs the endless Cryptid co-op build with repaired deck setup, typed exact-amount personal/team bets, physical reward dice and the boss wheel Space jackpot challenge. It automatically moves old Together, Steamodded/smods, Cryptid, Amulet and Talisman folders into the backup, including incomplete/older layouts, release-name variants, GitHub extraction wrappers, legacy Lua headers, and named Lua/JSON/TOML/ZIP files. Bounded nested detection preserves each item's original relative path and avoids scanning the libraries of unrelated identified mods. No old mod is permanently deleted. The bundled Steamodded, Amulet, Cryptid and Together are then installed and verified; failures roll back moved files and folders.

The normal application locates Steam libraries, checks the owned game's supported build, refuses installation while Balatro is open, and backs up profiles and replaced components. Other conflicting mod IDs are also moved into the backup. Unrelated mods remain. Unknown DLLs, unknown Together destinations and linked paths still require review. Windows can request administrator access when Steam's game folder is protected; that continuation validates and retains the original user's profile paths. No security policy or Steam libraries are modified. A desktop shortcut uses the owned game with `--disable-console`.

Backups are under `%AppData%\BalatroTogether\Backups`. Their `PreviousMods` folders contain replaced components; `Saves` contains the original profiles/settings, excluding Mods and bot caches. The installer does not perform in-place live-run recovery. Close the game first and start a fresh party after updating every player to this version.

To rebuild on Windows with .NET Framework 4.8 development tools, extract the easy-installer ZIP, keep `Manual Install.zip` beside the executable, and run `InstallerSource\Build.cmd`. `Build.cs` pins the embedded payload/DLL/game hashes. The normal user does not need to rebuild, run scripts or install Python.

`Install Balatro Together.exe --self-test <empty test directory>` exercises only synthetic game/profile fixtures created below that directory. It never installs into the real Steam or AppData paths. `results.json` records the results; the test fixtures remain available for inspection. `--preview <image.png>` renders the installer briefly off-screen without activating it or launching the game.

Validation: 23 installer scenarios passed. They cover fresh/update installs, incomplete and multiple old loader layouts, legacy scripts/metadata, Cryptid variants, nested wrappers, archive copies, preserved unrelated mod libraries, rollback of moved files and folders, running-game refusal, unknown DLLs, paths, original-user context and the quiet shortcut. UI was rendered and inspected. Real administrator-prompt and every Windows/Steam-folder configuration are not certified. This locally compiled executable is unsigned. If Windows refuses to run it, the complete manual installation package is also included; do not disable Windows security features.
